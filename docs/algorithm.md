# 算法方法说明（Method）

本文完整说明 FlapSim 扑翼微型飞行器上的**仿昆虫分层控制器**，以及它的训练和评估方法。描述对应论文主结果所用的最终配置：第 5 轮控制器加确认性检验 M1。实验过程、各轮结果与排错记录见 [FlapSim_full_report.md](FlapSim_full_report.md)。本文中每一项都标出了对应的代码位置（`experiments/algorithms/spike_steer/` 下，除非另注）。

---

## 0. 一段话概述

控制器分三层，结构仿照昆虫飞行控制：

1. **反射层**：PID 姿态/高度回路，每 2 ms 运行，负责稳定。
2. **转向肌层**：在某一拍发出 6 ms 的满转速电机脉冲。脉冲落在翅拍的哪个相位，决定它产生抬头还是低头力矩。
3. **下行指令层**：一个只有 2035 个参数的 LIF 脉冲神经网络（SNN）。它只读 IMU 和任务指令，输出两样东西：
   - 何时发脉冲（脉冲的"定时"）；
   - 交给反射层的俯仰设定值（"设定值权限"）。

指令门控让学习层只在执行机动指令期间（及其后 1 s）接管，其余时间与经典控制器逐拍相同。

训练分两步：先用替代梯度模仿最强的经典控制器，得到会飞、相位正确的起点；再用 OpenAI 进化策略（ES）直接优化机动得分，并加倾角安全惩罚。

评估比较的对象是"同预算重新调参的最强经典方案"，在每轮全新的盲测集上逐例配对，判据事先公开。

## 1. 问题设定

### 1.1 平台
- **机器人**：IST_robot-V2，15 g，单电机驱动双翼，翅拍约 26.7 Hz（周期约 37 ms），IMU 装在下体。
- **仿真**：MuJoCo 3.8.0 多体加叶素气动，升力按台架数据校准；控制步与仿真步都是 2 ms（DT）。
- **环境**：`topology_hover/environment.py: HoverEnv`。

### 1.2 接口（不改）
| | 内容 |
|---|---|
| 传感 | IMU 11 维 `[roll, pitch, yaw, gx, gy, gz, ax, ay, az, z, vz]`，500 Hz，含噪声；`z` 来自 ToF 测距（50 Hz、20 ms 延迟），`vz` 由 α-β 观测器估计 |
| 执行 | 云台 α、β ∈ ±0.3 rad；电机转速 ω ∈ [3115, 3807] rad/s；每 2 ms 更新，经 8.2 ms 一阶平滑 |

所有用例都是"应力用例"，包含以下扰动：
- 初始姿态 ±5°；
- 电机增益 ±1.5%；
- 传感器偏置；
- 1 步延迟；
- 周期性力与力矩脉冲。

悬停转速约 3140 rad/s，离电机下限只有约 25 rad/s，所以向下的权限很小。

### 1.3 任务与指令
机动在 T0 = 2.4 s 开始。任务指令 `cmd = [nod, dash] ∈ {0,1}²` 在 t ≥ T0 且目标未达成时为 1。目标是否达成由真值判定，这属于导航层职责，不在控制器接口内。

| 任务 | 目标 | 得分 J（越低越好） |
|---|---|---|
| 点头 nod | 尽快使 \|pitch\| ≥ 30° 并保持 0.1 s，再回到 < 5° | t30 + t_recover + 0.03·掉高(cm) + 0.5·漂移(m) + 坠落罚 |
| 前冲急停 dash | 沿航向前进 0.15 m 并停住（窗口 4 s） | t_reach + t_settle + 2·超调 + 0.03·掉高 + 0.5·侧偏 + 坠落罚 |
| 悬停 hover | 8 s 保持悬停（不发指令） | 俯仰 RMS(°) + 0.3·高度 RMSE(cm) |
| 大扰动恢复 upset | T0 时施加 20 ms 冲量力矩（不预告） | 倾角积分 + 0.2·高度变化 |

实现：`bench.py`。

## 2. 控制器

### 2.1 总览

```
                ┌────────────────────── 下行指令层（学习，SNN）──────────────────────┐
IMU 读数 ──► 特征 x[20] ──► 延迟线 ──► 8 LIF 隐层 ──► 2 LIF 输出(up/down) ──► fire ──┐
任务指令 ─┘                                     └──► 分级单元 g ──► ref = 0.7·tanh(g) │
                                                                       │            │
                ┌──────────── 反射层（PID）◄── 俯仰设定值 ref ◄────────┘            │
IMU 读数 ──────►│ α, β, ω = PID(reading; [0, ref])                                  │
                └──────────────┬──────────────────────────────────────────────────── │
                               ▼                                                     ▼
                      转向肌层：若 fire → 之后 3 拍 ω = 3807 rad/s（覆盖 PID 的 ω）
                               ▼
                        执行器（限幅、8.2 ms 平滑）
```

外层还有两样东西：
- **指令门控**（§2.6）：决定当前拍由学习层还是经典脉冲律提供 `fire` 和 `ref`。
- **翅拍不应期**（§2.7）：限制学习层的放电起始间隔。

### 2.2 一拍（2 ms）完整伪代码

```
输入：reading[11]（IMU+测距）, cmd[2], 时刻 t
x            = features(reading, cmd)                              # §2.4
(fire_n, g)  = SNN.step(x)                                         # §2.5，网络每拍都运行
fire_c       = law(reading, PLL.crank(t))                          # 经典锁相脉冲律，每拍都运行（§2.6）
on           = (cmd 任一为 1) 或 (距指令结束 < 1.0 s)                 # 门控
if on:  fire, ref = fire_n, 0.7·tanh(g)
        if fire 为新起始 且 距上次被接受的起始 < 37 ms: fire = 0     # 不应期
else:   fire, ref = fire_c, 0
        if 倾角(AHRS) > 25°: 本回合起 law ← pulse_tuned             # 翻正反射
α, β, ω = ReferencePID(reading, rpy_reference = [0, ref])           # §2.3
if t ≥ 1.5 s 且 (fire 或 脉冲进行中): ω = 3807                      # §2.8，脉冲持续 3 拍
执行 (α, β, ω)
```
- `t < 1.5 s` 为起飞保护：此时不放电，ref = 0。
- 学习层放电后，接下来 3 拍内不再判定新的放电。

### 2.3 反射层：PID（`robust_control/environment.py: ReferencePID`）

```
e      = rpy_reference − [roll, pitch]
rate   = 低通( d[roll, pitch]/dt )                 # 微分取测量值，避免设定值跳变冲击
effort = kp·e − kd·rate + ki·∫e dt                 # 积分限幅 ±0.3
[α, β] = trim + [effort_pitch, effort_roll]
ω      = ω₀ − kp_z(z − z_ref) − kd_z·vz + ki_z·∫(z − z_ref)
```
增益在应力悬停上做网格重调，相对原始基线为 kp × 1.5、kd × 0.85、ki × 1.5。全状态反馈上界只比它好 1.1° 倾角 RMS，说明悬停调节已经接近最优，学习层因此不去改悬停。

### 2.4 学习层输入：20 维特征（`bench.features`）

```
s   = reading[IDX] / SCALE            # IDX = [roll, pitch, gx, gy, gz, ax, ay, az]
                                      # SCALE = [0.1 rad ×2, 10 rad/s ×3, 25 m/s² ×3]
x   = [ max(s,0) (8维), max(−s,0) (8维), 1, 0, nod, dash ]
```
- **正负拆分**：每路都是非负驱动，类似 ON/OFF 通道，适合脉冲神经元。
- **尺度**：取翅拍振荡的典型幅度，网络可以把陀螺和加速度计上的翅拍振荡当成"时钟"。
- **不提供翅拍相位**：经典律直接从锁相环拿相位；学习层只能用延迟连接从振荡里自己构造相位。
- **看不到高度和升降速度**，高度只由反射层管。
- 常数 0 只是占位，兼容旧的 18 维布局。

### 2.5 下行指令层：延迟连接的 LIF SNN（`bench.DescendingNet`，torch 版 `descend.DescendingSNN`，两者逐拍一致）

**结构**

```
x[20] ─ 每条输入 11 档延迟（0, 2, …, 20 ms）, W_in[8,20,11] ─► 8 个 LIF 隐层神经元
隐层脉冲 ─ 11 档延迟（0..20 ms）, W_out[2,8,11] × 5 ─► 2 个 LIF 输出（up, down）
隐层脉冲 ─ 11 档延迟, W_g[8,11] × 5 ─► 1 个分级单元 g（τ_g = 20 ms 漏积分）
```

| 参数 | 形状 | 个数 |
|---|---|---|
| W_in | 8×20×11 | 1760 |
| b_h | 8 | 8 |
| W_out | 2×8×11 | 176 |
| b_o | 2 | 2（初值 −2，默认不放电） |
| W_g | 8×11 | 88 |
| b_g | 1 | 1 |
| **合计（ES 搜索维数）** | | **2035** |

膜时间常数 τ_m 与突触时间常数 τ_s 在模仿阶段可学（结果约 1.0–1.3 ms），ES 阶段固定。

**动力学**

每 2 ms 一拍分两个 1 ms 子步，其中 a_m = e^(−1 ms/τ_m)，a_s = e^(−1 ms/τ_s)：

```
I_h   = Σ_i Σ_k W_in[h,i,k] · x_i(t − 2k ms) + b_h
cur_h ← a_s·cur_h + (1 − a_s)·I_h
v_h   ← a_m·v_h  + (1 − a_m)·cur_h
s_h   = [v_h ≥ 1];   v_h ← v_h − s_h                         # 阈值 1，减法复位
I_o   = 5 · Σ_h Σ_d W_out[o,h,d] · s_h(t − d) + b_o  → 同样的 LIF → s_o
I_g   = 5 · Σ_h Σ_d W_g[h,d] · s_h(t − d) + b_g ;   g ← a_g·g + (1 − a_g)·cur_g
fire  = 两个子步内 s_up 或 s_down 任一为 1
ref   = 0.7 · tanh(g)                                        # 俯仰设定值，±0.7 rad
```

**输出的含义**

- **up 和 down 执行时是同一个动作**：一次电机脉冲。产生抬头还是低头力矩，完全由放电时刻落在翅拍的哪个相位决定（曲柄约 135° 抬头，约 315° 低头）。两个输出只是方便模仿学习分别学两种放电时机。
- **延迟线**：作用是让网络从 0–20 ms 的 IMU 振荡历史中推断翅拍相位。一个翅拍周期约 37 ms，20 ms 的历史超过半个周期。
- **分级单元**：给出俯仰设定值，由 PID 去跟踪，对应慢速、持续的姿态指令。

### 2.6 指令门控与经典脉冲律（`descend_gated.GatedLearned`）

**学习层何时在岗**

- **在岗**：nod 或 dash 指令为 1，或者指令结束后不到 1.0 s（`TAIL_S = 1.0`）。
- **不在岗**：使用经典锁相脉冲律 `law_tuned`，ref = 0，与经典悬停控制器逐拍相同。
- **翻正反射**：不在岗时，若 AHRS 倾角超过 25°，本回合改用翻正专用律 `pulse_tuned`。

**经典锁相脉冲律**（`pilot.py`）

```
crank = PLL(gy)                                  # 由俯仰陀螺锁相得到的翅拍相位
u     = −(k_θ·pitch + k_q·q_slow)                # q_slow：去掉翅拍振荡的慢俯仰角速度
ψ     = 135°（u > 0）或 315°（u < 0）
fire  = |u| > 阈值 且 |crank − ψ| < 窗宽/2         # 窗内电机保持满转速
```
两组参数：
- `law_tuned`：k_θ = 8.0，k_q = 0.4，阈值 0.5，窗宽 45°（悬停）；
- `pulse_tuned`：k_θ = 3.0，k_q = 0.4，阈值 0.5，窗宽 90°（翻正）。

网络和锁相环每拍都在运行，所以切换时状态是连续的。

**门控的后果**：悬停得分按构造等于经典（比值 1.000）；恢复比值固定为 1.050，因为 25° 之前用 law_tuned，对手全程用 pulse_tuned。对应的生物学类比是：下行神经元调制反射，而不是替代反射。

### 2.7 翅拍不应期（`descend_r4.RefractoryLearned`）

学习层在岗时，若某一拍是新的放电起始，且距上一次**被接受**的起始不足 37 ms（约一个翅拍），就取消这次放电。这样每个翅拍最多一次脉冲，类比果蝇转向肌每翅拍最多放电一次。不应期只作用于学习层。

已验证：不应期为 0 时与 GatedLearned 逐例相同。局限：它能抑制成串放电，但不能限制总放电量。

### 2.8 转向肌层

任一来源放电后，接下来 3 拍（6 ms，`TWITCH_TICKS = 3`）电机指令为 3807 rad/s，覆盖 PID 给出的 ω。

经过 8.2 ms 平滑后，脉冲到达电机时已被拉宽、削峰，一次脉冲约把转速顶高 692 rad/s。这在翅拍周期内形成非对称的升力，从而产生俯仰力矩。

## 3. 训练

### 3.1 第一步：模仿经典对手（`descend.py collect / train`）

**为什么要模仿**：从零开始用 NEAT 或强化学习，都找不到锁相放电解（初始化落在错误的盆地，目标在大片区域上是平的）。模仿约 15 分钟就能给出会飞、放电相位正确的起点。

**数据**：每个任务的最强经典对手（§4.1）在训练用例上飞，从 t ≥ 2 s 起逐拍记录 `[x(20), 是否放电, sign(u), ref]`。
- 训练用例：悬停 24、点头 16、冲刺 16、恢复 16；
- 验证用例：各任务 4 例。

标签：
```
y_up = 放电 且 u > 0      y_down = 放电 且 u < 0      r = ref / 0.7
```
放电率约 1–2%，所以正样本加权。

**损失与优化**

- **替代梯度**：前向用阶跃，反向用 σ((v − 1)/0.25) 的导数。输出放电概率 p 取两个子步内 σ((v − 1)/0.25) 的最大值。
- **损失**：
  ```
  L = mean[ (1 + 2y) · BCE(p, y) ] + 5 · mean[ (ref/0.7 − r)² ]
  ```
- **批与展开**：窗口 200 拍、步长 100 拍，每批 32 个窗口，BPTT 全展开。
- **优化器**：Adam，学习率 3e-3，梯度范数裁到 1，训练 40 轮，按验证损失选最优一轮。
- **时间常数**：τ_m、τ_s 以 log 参数化参与学习，裁在 0.3–10 ms。

结果：验证集放电精度约 0.45，召回约 0.65–0.70。不必完全复刻，只要求起点会飞、相位基本正确。

**加门控**：在模仿得到的 spec 上加门控参数：
- gate、tail_s = 1.0；
- base_law = law_tuned、upset_law = pulse_tuned、upset_tilt = 25°；
- refractory_s = 0.037。

第 5 轮各种子的起点 spec 已归档、逐字节固定：`artifacts/spike_steer/plan_v4/r5/train/imitate_spec_s{1..5}.json`。

### 3.2 第二步：OpenAI-ES 直接优化机动得分（`descend.py finetune`，第 5 轮配置 `descend_r5.py`）

**算法**

```
θ = flatten(W_in, b_h, W_out, b_o, W_g, b_g)                   # 2035 维；τ_m、τ_s 固定
for gen = 1 … 60:
    抽 16 个 ε_j ~ N(0, I)，取对称 ±ε_j 得 32 个候选 θ_j = θ ± 0.03·ε_j
    这一代抽一批新的训练用例：点头 8 + 冲刺 4；所有候选飞同一批（公共随机数）
    F_j = 目标函数(θ_j)  （见下）
    按 F_j 排名（最好排第 0）：u_j = max(0, ln(17) − ln(rank_j + 1))，u ← u/Σu − 1/32
    ĝ = (1/0.03) · Σ_j u_j · ε_j
    θ ← θ + Adam(ĝ)，学习率 0.02，β = (0.9, 0.999)
    每 5 代：保存中心 θ，并在固定 8 例验证集上记录
```

**目标函数（第 5 轮）**

```
F = Σ_t w_t · ( J̄_t / N_t + 0.3 · mean_episode∈t[ max(0, θ_peak − 60°) ] ) / Σ_t w_t ,   t ∈ {nod, dash}，w_nod : w_dash = 2 : 1
```
实现见 `descend_r3.composite_r3`；第 4 轮起阈值为 60°、系数为 0.3。
- J̄_t：任务 t 在本代用例上的平均得分。
- N：经典对手在训练分布上的归一化分母，所以 F 的前两项就是"相对经典的比值"。
- θ_peak：回合内真实倾角的峰值，单位为度，取自仿真真值。

几点说明：
- 倾角惩罚只作训练信号，控制器本身仍只看 IMU。
- 点头权重是冲刺的两倍，因为点头是瓶颈（§5）。
- 悬停和恢复不参与训练：门控下它们与学习层无关。

**用例与随机流**
- 训练用例：`make_case(2_096_200_000 + 100_000 + 100·gen + i, …, 'stress', i mod 8)`。
- ES 随机流种子：1000 + seed；断点续跑时用 [1000 + seed, gen] 重播种。

### 3.3 选中心（`reselect_r3.py`，第 5 轮 `N_VAL2 = 64`）

ES 的中心每 5 代保存一次，60 代共 13 个候选。每个候选在 64 个点头 + 64 个冲刺验证用例上飞（训练生成器偏移 60 000，与 ES 批次和盲测集都不重叠）。

选择规则：
1. 只保留零坠落、且所有回合真实倾角峰值 < 70° 的候选；
2. 其中按带惩罚的加权综合（与 §3.2 的 F 相同）取最低者。

为什么用 128 例：早期只用 8 或 16 例时，选出的中心在盲测上明显偏乐观。ES 越往后优化越容易变得冒进，大样本加安全约束可以把这种中心挡掉。

### 3.4 预算
- 每个种子：模仿 40 轮，加上 ES 60 代 × 33 候选 × 12 回合 ≈ 2.4 万回合，再加选中心 13 × 128 回合。
- 经典对手的调参预算是网格或 CEM，数百回合。

学习方预算远大于经典方，这一点需要在论文中说明。

## 4. 评估

### 4.1 对手：同预算重新调参的最强经典方案（`bench.py classical`）

每个任务在 8 个调参用例上，从几种经典方案中选出最强的一个作为对手：

| 任务 | 候选 | 最强对手 |
|---|---|---|
| 点头 | PID / 锁相脉冲律 / 设定值调度 | 设定值调度：go −0.6 rad × 9 拍，brake +0.2 rad × 6 拍 |
| 冲刺 | 同上 | 设定值调度：go +0.35 rad × 45 拍，brake −0.5 rad × 3 拍 |
| 悬停 | PID / 锁相脉冲律 | law_tuned |
| 恢复 | PID / law_tuned / pulse_tuned | pulse_tuned |

与"普通 PID"相比差距很大（点头约 5.16 对 0.85），但这个对比太弱，所以全部结论只对比最强经典方案。

### 4.2 盲测与配对
- 点头、冲刺：每一轮生成全新的 16 + 16 个盲测用例（M1 用基数 2_096_900_000）。学习方与对手在同一批用例上逐例配对。
- 悬停 16 例、恢复 48 例，各轮相同。
- **比值** = 学习方平均得分 ÷ 对手在同一盲测集上的**逐例中位数**（点头、冲刺），或 ÷ 对手均值（悬停、恢复）。学习方的均值包含坠落罚，这种取法对学习方更严。

### 4.3 主判据 M1（预注册，提交 `132b1e2`）
一个种子"通过"需要同时满足：
- (点头比值 + 冲刺比值)/2 ≤ 0.95；
- 悬停比值 ≤ 1.06；
- 恢复比值 ≤ 1.06；
- 机动盲测零坠落。

5 个种子中至少 3 个通过，M1 才成立。

检验条件：控制器冻结，盲测集全新，判据在学习控制器接触新集之前推送，只测一次。结果是 3/5 通过，详见报告 §8.9。

原主假设 H1（四项平均 ≤ 0.95）同样如实报告：未达到。原因是悬停和恢复按构造分别为 1.000 和 1.050，把机动成绩稀释了。

### 4.4 机制消融（`bench.evaluate_spec --variants`）

| 变体 | 改动 | 检验什么 |
|---|---|---|
| clamp_fast | 陀螺与加速度计的正负两路输入置 0 | 是否靠快通道（翅拍振荡）建立相位 |
| nodelay_all | 每条连接沿延迟轴求和，放到 0 档（总增益不变） | 延迟线是否有功能 |
| noref | W_g = 0、b_g = 0 | 机动是否需要设定值权限 |
| nopulse | b_o = −50（永不放电） | 脉冲转向肌是否必要 |

第 5 轮每个种子在每种消融下综合都恶化至少 38%，四种机制缺一不可。

### 4.5 ANN 对照（`descend_ann.py`）
用同样尺寸的 ANN 替换 SNN，训练流程相同。结果：模仿阶段 ANN 与 SNN 相当，ES 阶段三个 ANN 种子都没有超过起点。所以本文**不主张**脉冲载体本身带来性能优势，主张的是分层结构加脉冲定时机制。

## 5. 设计取舍：试过、但没有进入最终方法的做法

| 做法 | 结果 | 为什么不用 |
|---|---|---|
| 纯 IMU 端到端 NEAT / PPO 悬停 | 0/192 严格成功 | 没有反射层学不会悬停，保留 PID 反射层 |
| NEAT 进化 LIF 回路（v1–v5c） | 最好与经典持平，不可靠 | 改为模仿起点 + ES |
| PID + SNN 残差 | SNN ≈ ANN，重调 PID 就比残差好 | 学习层改为只管机动（门控） |
| 学习层全程接管、四任务一起优化（第 1 轮） | ES 牺牲悬停换机动（悬停比值 1.37–1.50） | 加指令门控与翻正反射 |
| 倾角惩罚阈值 45°（第 3 轮） | 点头变保守，0/3 过 H1 | 放宽到 60°、系数 0.3，加不应期（第 4 轮起） |
| 每候选 32 例、30 代（第 6 轮） | 种子 4、5 盲测综合 0.978 / 0.981，未达 H1；种子 1–3 未完成即停止 | 主结果用第 5 轮 |
| 每代安全检查回滚（safe ES，种子 1） | 30 代中撤回 11 代，点头未变快 | 探索性，未采用 |
| 奖励上限 + 脉冲惩罚 + 中途扰动（第 7 轮试验，MonoRace 启发） | 明显差于对照组 | 停止，负面结果存档 |
