## 1. 结论

### 1.1 一句话

在一台用台架升力数据校准过的单电机双翼扑翼机器人仿真上，一个仿昆虫分层的控制器（PID 反射层 + 翅拍锁相的电机脉冲"转向肌"层 + 学习得到的脉冲神经网络"下行指令"层）在它所控制的机动任务（点头、前冲急停）上，比同预算下最强的经典方案好 5% 以上，同时悬停和大扰动恢复不劣、机动盲测零坠落。这一结论在冻结控制器、全新盲测集、事先公开判据的确认性检验（M1）中得到支持，但余量很小（5 个种子中 3 个通过，第 3 个仅以 0.0005 过线）。

### 1.2 结论状态

| 结论 | 状态 | 主要证据 |
|---|---|---|
| **M1：机动优于最强经典方案 5% 以上，悬停/恢复不劣，零坠落** | **成立（3/5）** | §8.9；`artifacts/spike_steer/confirm_m1/` |
| 冲刺优于经典 | 成立（第 4 轮最稳定） | 第 4 轮 5 个种子冲刺 0.82–0.87、每个种子 16/16 配对全胜；第 5 轮 5 个种子中 2 个 ≤ 0.87、16/16 全胜，种子 2、3 约持平（0.998、1.008） |
| H3：四种机制缺一不可（快通道、延迟、目标角、脉冲） | 成立（第 2–5 轮每个种子） | 消融后综合恶化 +20% 至 +300%（第 5 轮每个种子 ≥ +38%） |
| H5：机动盲测零坠落 | 成立（第 4 轮 4/5，第 5 轮 5/5，M1 160/160 回合） | §8.5、§8.6、§8.9 |
| H4：同尺寸 ANN 与 SNN 相当（不主张脉冲载体带来性能） | 成立（预期之内） | §8.2 |
| 原 H1：四项综合 ≤ 0.95（≥ 3/5） | **不成立**（六轮均未达到；最好第 5 轮 2/5） | §8 |
| 点头优于经典 | 不稳定（种子之间 0.857–1.064） | §8.6、§8.9 |

### 1.3 必须如实说明的局限

1. **M1 是在六轮之后提出的。** 原主假设 H1 把悬停和大扰动恢复也平均进综合分；这两项学习层不参与（门控关闭，悬停按构造 1.000，恢复固定 1.050），掺进去稀释了学习层的成绩。M1 改为只评价学习层控制的机动，另两项作不劣条件。M1 的检验本身是干净的（判据先推送、控制器冻结、数据全新、只测一次），但"换判据"这个决定是看过前六轮结果后做的。论文必须同时报告原 H1 的结果。
2. **余量很小。** 种子 2 的 M1 分数 0.9495，换一套盲测集可能变成 2/5。
3. **点头优势不稳定。** 种子 5 的点头不如经典（1.064）；种子 1、3 点头逐例只胜 9/16。
4. **多轮迭代的研究者自由度。** 第 2–5 轮共 17 个种子-轮次盲测中，只有 3 个原 H1 综合 ≤ 0.95。只挑最好的报告会夸大效果。
5. **纯仿真**；学习方预算（模仿 40 轮 + ES 数十代 × 32 候选 × 12 回合）远大于经典调参预算（网格/CEM 数百回合）。

## 3. 平台与接口

### 3.1 机器人与仿真
- **机器人**：IST_robot-V2，15 g（推力单元 7 g + 下体 8 g，IMU 在下体），单电机驱动双翼，翅拍约 26.7 Hz（周期约 37 ms）。
- **仿真**：MuJoCo 3.8.0 多体 + 自研叶素气动；升力按单翼定基座台架数据（10–15 Hz，36 次测量）校准（作者章节）。
- **环境类**：`experiments/algorithms/topology_hover/environment.py` 的 `HoverEnv`（`sensor_mode='height'`），经 `snn_pid_compare` / `hover9` / `pid_airborne` 封装；每个仿真步 2 ms。

### 3.2 传感（接口，不变）
- IMU 11 维读数：`[roll, pitch, yaw, gx, gy, gz, ax, ay, az, z, vz]`，500 Hz。姿态噪声 0.02°、陀螺噪声 0.002 rad/s、加速度噪声 0.02 m/s²。
- 高度：朝下的 ToF 测距模型（`topology_hover/sensors.py: HeightSensor`），50 Hz，20 ms 延迟，2 mm 噪声，量程 5 cm–2 m，按测得姿态做倾斜校正；升降速度由 α-β 观测器（α = 0.30，β = 0.035/0.02）从测距值估计，不用真值。
- 经典 PID 使用全部 11 维；**学习层只用其中 8 维**（§5.3），看不到高度和升降速度。

### 3.3 执行（接口，不变）
| 量 | 范围 | 说明 |
|---|---|---|
| 云台 α、β | ±0.3 rad | 改推力方向 |
| 电机转速 ω | 3115–3807 rad/s | 均值管升力，翅拍周期内的调制管俯仰力矩 |
| 更新 | 每 2 ms，8.2 ms 一阶平滑 | 6 ms 脉冲到达电机时已被拉宽削峰 |

应力用例里实际悬停转速约 3140 rad/s，**电机下限只比悬停低约 25 rad/s**，高度回路向下的权限极小；一次脉冲把转速顶高约 692 rad/s。这是高度越界的物理根源（§9.3）。

### 3.4 回合终止（任一即算坠落）
倾角 > 1.4 rad（80.2°）→ `tilt`；高度偏离起点 > 1 m → `height_escape`；离地 < 0.12 m → `low_height`；数值发散 → `numerical`（`pid_airborne/core.py`）。

### 3.5 应力用例（`topology_hover/environment.py: case(..., condition='stress')`）
初始姿态 ±5°；电机增益随机 ±1.5%；加速度计偏置 0.01；姿态偏置 0.05°；传感器延迟 1 步；周期性力脉冲 0.006 N、力矩脉冲 8×10⁻⁶ N·m。所有训练、验证和盲测用例都是应力用例。

## 4. 综合基准（`experiments/algorithms/spike_steer/bench.py`）

### 4.1 四个任务与打分（越低越好；DT = 2 ms；T0 = 2.4 s）

| 任务 | 时长 | 定义 | 得分 J |
|---|---|---|---|
| T1 应力悬停 | 8 s | 保持悬停 | 俯仰 RMS(°，2 s 后) + 0.3 × 高度 RMSE(cm)；坠落：40 − 飞行时长 |
| T2 点头 | 5 s | T0 起尽快使 \|俯仰\| ≥ 30° 并保持 0.1 s，再尽快回到 < 5° | t30 + t_recover + 0.03×掉高(cm) + 0.5×漂移(m) + 坠落罚；未达成各计 2.5 s；坠落罚 = 10 + 5 × 未飞完比例 |
| T3 前冲急停 | 6.5 s | T0 起沿航向前飞 0.15 m 并停住（窗口 4 s） | t_reach + t_settle + 2×超调(超出 0.1 m 的部分) + 0.03×掉高 + 0.5×侧偏 + 坠落罚；未到达计 4 s + 2×差距 |
| T4 大扰动恢复 | 5 s | T0+[0, 0.04] s 时施加 20 ms 冲量力矩，8 方向 × 3 校准水平 × 2（半数有第二击），窗口 2.5 s | 击前与击后倾角积分 + 0.2×高度变化(cm)；坠落 60 + 40×未飞完比例 |

- T3 目标 0.15 m 由预注册规则产生（经典调度在 0.25 m 时 0/16 到达，取第 12 大行程 0.152 m）。
- T4 冲量强度按方向类（横滚、俯仰、对角）在 1–40 mN·m 对数网格上读等渗存活曲线校准（`upset_v2.py`），三档对应经典 PID 存活率约 80%、50%、20%。

### 4.2 指令信号
点头指令在 t ≥ T0 且目标未达成时为 1；冲刺同理（前进 0.15 m 为达成）；悬停、恢复恒为 0（扰动不预告）。目标达成由真值判定（导航层职责，不在 IMU 接口内）。

### 4.3 经典对手（同预算调参，`bench.py classical`）

每个任务在 8 个调参用例上调出最强经典臂：

| 任务 | 候选臂 | 对手（最强） |
|---|---|---|
| 悬停 | pid / law_tuned | **law_tuned**：PID + 锁相脉冲律（k_θ = 8.0，k_q = 0.4，阈值 0.5，窗宽 45°；108 点网格） |
| 点头 | pid / law_tuned / schedule | **schedule**：设定值调度（go −0.6 rad × 9 拍，brake +0.2 rad × 6 拍） |
| 冲刺 | 同上 | **schedule**（go +0.35 rad × 45 拍，brake −0.5 rad × 3 拍） |
| 恢复 | pid / law_tuned / pulse_tuned | **pulse_tuned**：翻正调参脉冲律（k_θ = 3.0，k_q = 0.4，阈值 0.5，窗宽 90°） |

对比"普通 PID"差距很大（点头 PID 约 5.16，学习层约 0.85），但这个对比太弱，全部结论都对比最强经典方案。

### 4.5 盲测集
- 点头、冲刺：每轮一套全新的 16 + 16 例（`maneuver_v2.cases(base, 16, task)`）。
- 悬停：16 例（`pilot.cases('test', 16, 8.)`），第 1 轮起不变。
- 恢复：48 例（`upset_v2` 测试基数 2_070_400_000），第 1 轮起不变。学习层在这两项上按构造等于经典，所以不换集不影响学习层评价。

### 4.6 假设
| 假设 | 内容 | 门槛 |
|---|---|---|
| 原 H1 | 四项综合（各 25%）≤ 0.95 且悬停 ≤ 1.05 | ≥ 3/5 种子 |
| H1′ | 每项 ≤ 1.05，且点头/冲刺一项 ≤ 0.90、配对符号检验 p < 0.05 | ≥ 3/5 |
| H2 | 点头、冲刺、恢复中 ≥ 2 项 ≤ 0.90 | ≥ 3/5 |
| H3 | 四种消融使综合恶化 ≥ 10% | 每种子 |
| H4 | 同尺寸 ANN ≈ SNN | — |
| H5 | 32 个机动盲测回合零坠落 | ≥ 3/5 |
| **M1** | (点头+冲刺)/2 ≤ 0.95，悬停 ≤ 1.06，恢复 ≤ 1.06，零坠落 | ≥ 3/5 |

**算术约束**：悬停按构造 1.000、恢复 1.050，所以原 H1 等价于"点头和冲刺平均 ≤ 0.848"，即两项都要比经典好约 15%。这是六轮都未达到 H1 的结构性原因，也是 M1 提出的理由。

## 5. 控制器：三层结构的完整实现

### 5.1 一拍（2 ms）之内

```
reading[11] = IMU + ToF 测距                                  ← 接口不变
cmd[2]      = [nod, dash]                                      ← 任务指令
x[20]       = features(reading, cmd)                           ← §5.3
(fire, ref) = 下行指令层.act(x)                                 ← §5.4；fire ∈ {0,1}，ref ∈ [−0.7, 0.7] rad
PID.rpy_reference = [0, ref]                                   ← 俯仰设定值交给反射层
[α, β, ω]   = PID.step(reading)                                ← §5.2
if fire and t ≥ 1.5 s: ω = 3807 rad/s（持续 3 拍 = 6 ms）     ← §5.5 转向肌层
执行器 ← clip，8.2 ms 平滑
```

经典对手和学习方的区别只在"下行指令层"这一格。

### 5.2 反射层：`ReferencePID`（`robust_control/environment.py`）
```
e      = rpy_reference − [roll, pitch]
rate  ← 低通(d[roll, pitch]/dt)                    # 微分取测量姿态，不取设定值跳变
effort = kp·e − kd·rate + ki·∫e dt                 # 积分限幅 ±0.3
[α, β] = trim + [effort_pitch, effort_roll]
ω      = ω₀ − kp_z(z − z_ref) − kd_z·vz + ki_z∫(z − z_ref)
```
增益在应力悬停上网格重调：相对基线 kp × 1.5、kd × 0.85、ki × 1.5（`PID_GAINS = (1.5, .85)`）。全状态反馈上界只比它好 1.1° 倾角 RMS（悬停调节已近最优）。

### 5.3 学习层输入：20 维（`bench.features`、`pilot_v6.IDX/SCALE`）

| 下标 | 内容 | 尺度 |
|---|---|---|
| 0–7 | max(x, 0)：roll, pitch, gx, gy, gz, ax, ay, az | 0.1 rad；10 rad/s；25 m/s² |
| 8–15 | max(−x, 0)：同上 | 同上 |
| 16 | 常数 1 | 偏置 |
| 17 | 常数 0 | 占位（兼容旧 18 维布局） |
| 18 | 点头指令 | 0/1 |
| 19 | 冲刺指令 | 0/1 |

正负拆分让每路都是非负驱动（类似 ON/OFF 通道）；尺度取翅拍振荡的典型幅度，使网络可把振荡当"时钟"。**学习层看不到翅拍相位**（经典律用锁相环直接获得），必须用延迟连接从陀螺/加速度计振荡自己构造。

### 5.4 下行指令层：`DescendingNet`（NumPy，`bench.py`）= `DescendingSNN`（torch，`descend.py`），逐拍一致

```
x[20] ──(每条输入 11 档延迟 0,2,…,20 ms；W_in[8,20,11])──► 8 个 LIF 隐层
隐层脉冲 ──(11 档延迟 0..20 ms；W_out[2,8,11] × spike_scale 5)──► 2 个 LIF 输出 up / down
         ──(W_g[8,11] × 5)──► 1 个分级单元 g（τ_g = 20 ms 漏积分）──► ref = 0.7·tanh(g)
```

| 参数 | 形状 | 个数 |
|---|---|---|
| W_in | 8×20×11 | 1760 |
| b_h | 8 | 8 |
| W_out | 2×8×11 | 176 |
| b_o | 2 | 2（初值 −2，默认不放电） |
| W_g | 8×11 | 88 |
| b_g | 1 | 1 |
| τ_m, τ_s | 共享 | 2（模仿阶段可学，约 1.0–1.3 ms；ES 阶段固定） |
| **合计** | | **2035**（ES 搜索 2035 维） |

**动力学**（每拍两个 1 ms 子步，a_m = e^(−1 ms/τ_m)，a_s = e^(−1 ms/τ_s)）：
```
I_h = Σ_i Σ_k W_in[h,i,k]·x_i(t − 2k ms) + b_h
cur_h ← a_s·cur_h + (1 − a_s)·I_h ;  v_h ← a_m·v_h + (1 − a_m)·cur_h
s_h = [v_h ≥ 1];  v_h ← v_h − s_h                          # 阈值 1，减法复位
I_o = 5·Σ_h Σ_d W_out[o,h,d]·s_h(t − d ms) + b_o ;  同上得 s_o
I_g = 5·Σ_h Σ_d W_g[h,d]·s_h(t − d ms) + b_g ;  g ← a_g·g + (1 − a_g)·cur_g
fire = s_up 或 s_down 在两个子步内任一为 1 ；  ref = 0.7·tanh(g)
```

**输出含义**：up 和 down 执行时是同一个电机脉冲，方向完全由放电时刻决定（曲柄约 135° 抬头、约 315° 低头）。分级单元给出俯仰设定值（"设定值权限"）。起飞后 1.5 s 内不放电、ref = 0；放电后 3 拍内不再判定。

### 5.5 转向肌层
任一来源放电 → 接下来 3 拍（6 ms）电机指令 = 3807 rad/s（`TWITCH = 3`）。生物对应：果蝇转向肌每翅拍最多放电一次，放电相位决定力矩。

### 5.6 指令门控（第 2 轮起，`descend_gated.GatedLearned`）
```
学习层在岗 = (nod 或 dash 指令为 1) 或 (指令刚结束且 < 1.0 s)       # TAIL_S = 1.0
在岗：输出 (fire_net, ref_net)
不在岗：输出 (law_tuned 放电, ref = 0)                              # 与经典悬停控制器逐拍相同
翻正反射（修正 1）：不在岗且 AHRS 倾角 > 25° → 本回合改用 pulse_tuned
```
网络和锁相环每拍都运行（状态连续）。后果：悬停按构造 = 1.000；恢复 = 1.050（25° 阈值前用 law_tuned、之后用 pulse_tuned，对手全程 pulse_tuned）。对应昆虫"下行神经元门控反射、不替代反射"。

### 5.7 翅拍不应期（第 4 轮起，`descend_r4.RefractoryLearned`）
学习层在岗时，若本拍是新的放电起始且距上一次被接受的起始 < 37 ms，则取消。只作用于学习层；经典律不受影响。已验证：不应期 = 0 时与 GatedLearned 逐例相同，37 ms 时与 HomePC 诊断版逐例相同（12 个训练回合）。**局限**：上限约每秒 27 次，能抑制成串放电，不能限制总放电量（§9.4）。

### 5.8 消融（`bench.evaluate_spec --variants`）
| 变体 | 改动 | 检验 |
|---|---|---|
| clamp_fast | 陀螺 + 加速度计正负两路置 0 | 是否靠快通道建立相位 |
| nodelay_all | 各权重沿延迟轴求和放到 0 档（总增益不变） | 延迟档是否有功能 |
| noref | W_g = 0，b_g = 0 | 机动是否需要设定值权限 |
| nopulse | b_o = −50（永不放电） | 脉冲转向肌是否必要 |

## 6. 训练：模仿 + 进化策略

### 6.1 第一步：模仿（`descend.py collect / train`）

**为什么**：从零用 NEAT 或 RL 搜不到锁相解（初始化盆地、单向平台；10-08、10-12/13）。模仿能在约 15 分钟内给出会飞且相位正确的起点。

**数据**（`TracedClassical`）：每个任务的经典对手在训练用例上飞，t ≥ 2 s 起逐拍记录 [x(20), 是否放电, sign(u), ref]。训练集每任务用例数：悬停 24、点头 16、冲刺 16、恢复 16（偏移 0）；验证集各 4（偏移 50 000）。标签：
```
y[0] = 放电 且 u > 0（up）    y[1] = 放电 且 u < 0（down）    r = ref / 0.7
```
放电率约 1–2%。

**训练**：替代梯度（反传用 σ((v − 1)/0.25) 的导数）；输出单元放电概率 p = 子步内 σ((v − 1)/0.25) 的最大值。
```
L = mean[ w · BCE(p, y) ] + 5 · mean[ (ref/0.7 − r)² ]，   w = 1 + 2y（正样本权重 3）
```
窗口 200 拍、步长 100 拍、批 32 个窗口、BPTT 全展开；Adam 3e-3，梯度范数裁到 1，40 轮，按验证损失选最优轮次；τ_m、τ_s 以 log 参数化参与学习（裁在 0.3–10 ms）。验证集精度约 0.45、召回 0.65–0.70。

**门控起点**：第 2 轮 `descend_gated.prepare` 在模仿 spec 上加 gate、tail_s、base_law = law_tuned、upset_law = pulse_tuned、upset_tilt 25°；第 4 轮起再加 `refractory_s = 0.037`。**第 2–6 轮及 M1 的起点 spec 逐字节相同**（`plan_v4/r5/train/imitate_spec_s*.json`）。

### 6.2 第二步：OpenAI-ES（`descend.py finetune`）

```
θ = flatten(W_in, b_h, W_out, b_o, W_g, b_g)            # 2035 维
每一代：
  抽 16 个高斯扰动 ε_j（对称成 32 个），候选 θ ± 0.03·ε_j，再加中心 θ
  每个候选在同一批新训练用例上飞（公共随机数）
  适应度 f_j = −目标值
  秩效用 u_j = max(0, ln(17) − ln(rank_j + 1))，归一化后减 1/32
  ĝ = (1/0.03) Σ_j u_j ε_j ；  θ ← θ + Adam(ĝ)，学习率 0.02（β = 0.9, 0.999）
  每 5 代：中心在固定 8 例验证集上飞，保存 spec_val_g<gen>.json
```
随机流种子 1000 + seed；断点续跑时按 [1000 + seed, gen] 重播种。

**各轮训练目标与批量**

| 轮次 | 每候选每代用例 | 目标（每任务一项，按权重平均） | 代数 |
|---|---|---|---|
| 1 | 四任务各 2 | 四任务比值，40/20/20/20 | 30–40 |
| 2 | 点头 4 + 冲刺 4 | 平均比值，1:1 | 60 |
| 3 | 同上 | 比值 + max(0, 真实倾角峰值 − 45°) × 0.1 | 60 |
| 4 | 同上 | 比值 + max(0, 倾角峰值 − 60°) × 0.3 | 60 |
| **5** | **点头 8 + 冲刺 4** | **同第 4 轮，点头 : 冲刺 = 2 : 1** | **60** |
| 6 | 点头 16 + 冲刺 16 | 同第 5 轮 | 30 |
| v5 | 同第 5 轮 | 同第 5 轮 + 每代安全检查 | 40（停在 30） |
| 7 小试验 B | 同第 5 轮 | + 点头比值下限 0.85 + 每脉冲 0.001 | 30（停在 13–15） |

倾角惩罚用仿真真值倾角，只作训练信号；控制器仍只看 IMU。

**用例来源**：训练用例 `make_case(2_096_200_000 + offset + i, …, 'stress', i % 8)`，ES 第 g 代偏移 100 000 + 100g。

### 6.3 safe ES（plan v5，`descend_safe.py`，探索性）
每代更新后，新中心飞 64 + 64 个独立安全用例（偏移 150 000）；任一坠落或倾角 ≥ 70° → 撤回本代（θ 与 Adam 矩恢复），代数推进、下一代换新扰动。实现方式：每次让 `descend.finetune` 断点续跑一代，再检查/回滚。撤回路径用强制失败测试过。

## 9. 诊断与发现

### 9.1 冲刺是最可靠的优势
第 4 轮 5 个种子冲刺都比经典好 13–18%，每个种子 16/16 配对全胜；第 5 轮和 M1 复测中，冲刺的最好种子仍好约 15%，但个别种子只是持平（第 5 轮种子 2、3；M1 种子 3）。原因：学习层同时用设定值与锁相脉冲，经典调度只能用设定值。

### 9.2 点头是瓶颈：更快与更安全冲突
点头需要大幅俯仰再快速回正，正好落在 80° 发散振荡的危险区。第 2 轮坠落回放（`plan_v4/r3/diag/trace_crash_s2_g29.py`）：点头后段学习层激发 3–4 Hz 发散俯仰振荡，真实倾角 0.7 s 内 54° → 1° → 42° → 72° → 80°；AHRS 严重滞后（真实 72° 时读 33°），基于 AHRS 倾角的反射包络（35°–60° 五档）一次都救不回。

### 9.3 高度越界机制（HomePC，`plan_v4/r3/diag/height_escape.md`）
越界向上。学习层在岗期间（尤其指令结束后 1 s 尾巴）每秒放电 10–24 次，每次把电机顶到 3807 rad/s；高度 PID 需求低于电机下限 3115 rad/s、全程饱和，无力下压；交还时已在 +0.67 m、+0.33 m/s，交还后经典律仍以约 12 次/s 放电，惯性滑行越过 +1 m。学习层看不到高度，得分也不罚爬升。

### 9.4 不应期的教训
事后给 7 个已选控制器加"每翅拍最多一次"：越界 4 → 0，但翻倒 5 → 19（`plan_v4/r4/precheck/`）——脉冲节奏同时在当俯仰刹车。搜索时就加，ES 学会每拍都放，冲刺平均脉冲数 62–80 → 97，越界又出现（中途快照坠落率 2.3%）。

### 9.5 ES 越优化越危险
第 4、5 轮每个中心在相同 128 例上的坠落：起点 0/10 坠落；第 0–19 代 24/40（60%）的中心至少坠落一次；第 20 代以后 64/80（80%）。原因：每候选只飞 12–32 个用例，1–3% 的坠落率大多看不到；秩效用又抹平了坠落的严重程度；倾角惩罚的预警区间很窄。第 6 轮把用例增到 32、plan v5 加安全检查、第 7 轮改奖励，都没能在保持安全的同时提高点头速度。

### 9.6 选中心样本量
坠落率 1–3% 时，16 例全部不坠落的概率是 62–85%。第 4 轮 16 例选中的 5 个中心里 4 个在 128 例上会坠落；改用 128 例后，第 5 轮盲测 5/5 零坠落（代价是常退回早期代）。

### 9.7 8 例验证偏乐观
种子 4（第 5 轮）：8 例 0.778，128 例 1.045。第 7 轮 B 组种子 1 第 9 代：8 例全部飞完、0.954，128 例坠落 16 次。

### 9.8 跨机器复现
经典对手 371/372 回合跨机器结局一致；同种子搜索前约 45 代逐位一致，之后被放大（第 4 轮 HomePC 与 LabHPPC 复刻）；评估（选中心、盲测）一致到 2×10⁻⁶。

### 9.9 两项探索性试验（均无可靠证据）
从第 4 轮种子 2 热启动、再搜 10 代，在相同 256 个训练用例上：

| 做法 | 点头翻倒 | 冲刺坠落（越界） | 总坠落 |
|---|---|---|---|
| 原控制器 | 2 | 3（3） | 5 |
| 加高度输入（24 维） | 4 | 1（1） | 5 |
| 加爬升惩罚（> 0.35 m × 1.0/m） | 2 | 0 | 2 |
| 两者都加 | 11 | 3（2） | 14 |

后两组目标相同、只差输入，坠落 2 对 14：同一起点再搜 10 代的随机波动大于改动效果；且缺少"不加惩罚、同样再搜 10 代"的对照。

### 11.3 第 5 轮 + M1 的完整复现命令（仓库根目录，`OMP_NUM_THREADS=1`）

```bash
# 0. 自检
python -W ignore -m experiments.algorithms.spike_steer.descend_r5 selftest
# 1. 模仿起点（已归档，逐字节固定）：artifacts/spike_steer/plan_v4/r5/train/imitate_spec_s{1..5}.json

python -W ignore -m experiments.algorithms.spike_steer._local.fresh_baseline --base 2_096_600_000 --round 5 \
       --output runs/spike_steer/bench_r5 --workers 30
python -W ignore -m experiments.algorithms.spike_steer.descend_r5 prepare --output runs/spike_steer/bench_r5 --source runs/spike_steer/bench_r4
# 3. 搜索（每个种子；60 代）
W=10 GENS=60 HOURS=24 PY=python bash artifacts/spike_steer/v4/handoff_s3/run_r5_seed.sh 1
# 4. 128 例选中心 + 盲测 + 消融
python -W ignore -m experiments.algorithms.spike_steer.descend_r5 reselect --output runs/spike_steer/bench_r5 --seed 1 \
       --spec artifacts/spike_steer/plan_v4/r5/finetune_s1 --workers 30
python -W ignore -m experiments.algorithms.spike_steer.descend_r5 evaluate --output runs/spike_steer/bench_r5 --seed 1 \
       --spec <selected spec_val_g*.json> --tag r5_s1 --variants intact,clamp_fast,nodelay_all,noref,nopulse
# 5. 确认性检验 M1
python -W ignore -m experiments.algorithms.spike_steer._local.fresh_baseline --base 2_096_900_000 --round 0 \
       --output runs/spike_steer/bench_m1 --workers 30
python -W ignore -m experiments.algorithms.spike_steer.confirm_m1 selftest
python -W ignore -m experiments.algorithms.spike_steer.confirm_m1 run --workers 30
```

## 13. 写论文的建议

### 13.1 建议的主张
"一个仿昆虫分层控制器——经典反射层 + 翅拍锁相的电机脉冲转向肌层 + 只在机动指令期间接管的脉冲神经网络下行指令层——在它所控制的机动上比同预算最强经典方案好 5% 以上，悬停与扰动恢复不劣，且机动盲测零坠落；四个机制组件缺一不可。"同时写明：该主假设（M1）在六轮迭代后提出，并在冻结控制器与全新数据上做了一次预注册检验（3/5，余量很小）。

### 13.2 建议的结构与图
1. 引言：扑翼微型机器人的机动控制；昆虫的分层（平衡棒反射、转向肌、下行神经元）。
2. 平台与基准（§3、§4）。图：机器人与四个任务示意；接口表。
3. 控制器（§5）。图：三层结构框架图（`docs/flapsim_review.html` 第一张）；LIF 与延迟连接示意；门控时序。
4. 训练（§6、§7）。图：训练与评估流程图（网页第二张）。
5. 结果：M1 主表与逐种子图；两套盲测集稳定性；消融（H3）；零坠落（H5）。
6. 分析：冲刺为何稳定占优、点头为何难（§9.1–9.2）；"越优化越危险"热力图（§9.5）；高度越界机制（§9.3）；跨机器复现（§9.8）。
7. 讨论与局限（§1.3）：多轮迭代与判据变更、余量、纯仿真、预算不对等；与端到端学习（如 MonoRace）对比；未来工作：带硬约束的搜索、PPO + 替代梯度、实物验证。
8. 补充材料：全部六轮表（§8）、问题清单（§10）、预注册索引（§14.3）、负面结果（§8.8、§8.10、§9.9）。

### 13.3 投稿前可能被问到、尚未做的
- 敏感性分析：升力增益 ±10%、电机增益 ±3% 下排名是否变化（电机增益已有接口，升力增益需新加）。
- 经典对手是否允许轨迹优化（目前只用调度网格/CEM）。
- 更多种子或第二套新集的复测（M1 余量小）。
- 实物验证。
