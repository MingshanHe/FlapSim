# 研究计划 B'：进化出的脉冲回路能否从原始 IMU 重新发现翅拍同步转向？

写于 2026-10-13 16:45，用户已接受论文定位（HANDOFF 第 0 节）。本文件是预注册：判据、消融、分析在跑之前写定；跑完只填结果，不改判据。

## 1. 主张与边界

**核心主张**：在原 v3 接口内（IMU + 测距，云台 ±0.3 rad，电机 3115–3807 rad/s，2 ms 更新、8.2 ms 平滑），NEAT 进化的带延迟脉冲回路可以**只从原始 IMU 信号**（不给锁相环、不给相位编码）学会"在特定翅拍相位发出单边电机脉冲来转向"，其控制性能与**同预算调参的经典方案（PLL + 阈值脉冲律）持平**，并且进化出的回路有可解释的机制：一个（或几个）神经元对陀螺/加速度计的翅拍振荡做阈值检测充当相位参考，经突触延迟把放电对齐到有效相位，再与姿态需求做"与"门。

**明确不主张**：性能优于经典律。全部已知事实（v3/analysis.md、fullstate_report.md）表明原接口内不存在这种优势。

**为什么这不平凡**（相对 v1–v5）：v1–v5 都给了 PLL 相位的 8 格 one-hot 编码，于是最优解是一个线性阈值单元。B' 去掉相位编码后，网络必须自己从 10.7 rad/s 的翅拍振荡里提取相位并定时，这正是 NEAT 的拓扑搜索和延迟基因唯一真有活干的地方。

## 2. 任务与环境（不变）

- `ResearchEnv(mode='direct', task='hover')`，应力案例（`topology_hover.environment.case(..., 'stress')`），每 2 s 一次 0.2 s 的力/力矩脉冲扰动，电机增益 1±1.5%。
- 云台与高度：重调 PID（kp×1.5），与 v1–v5 和经典律完全相同。网络只决定"这一拍电机指令是否拉到上限"。
- 目标 J = 俯仰 RMS（°，t ≥ 2 s）+ 0.3 × 高度 RMSE（cm）；坠机 J = 40 − 飞行秒数。与 v1–v5 相同。

## 3. 网络与编码

- 输入 18 维，全部是原始 IMU 读数的整流对（+、−）：AHRS 滚转、俯仰（/0.1 rad）；陀螺 x、y、z（/10 rad/s）；加速度计 x、y、z（/25 m/s²）；再加 2 维常数偏置输入（1、0）便于阈值设定。**不含**测距高度、不含 PLL 相位、不含陷波后的角速度。
- 输出 2 个脉冲神经元（上推/下推，命名只用于分析，网络不知道）；任一输出放电 → 电机指令在接下来 `twitch` 拍拉到上限（校准旋钮，1–3 拍）。
- 单元：当前电流型 LIF（1 ms 子步、阈值 1、减法重置）；突触延迟 0–20 ms（基因）；τ_m、τ_s 为基因组级基因（增益保持的改变，pilot_v4）。
- 起点：NEAT 经典起点（输入直连输出、无隐层、静息沉默先验 bias~N(−2, 0.5)、权重 N(0, 0.5)），允许加节点/加边（node_add 0.1，conn_add 0.2），pilot_v5 的冷启动变异率。
- 校准（与经典律同预算，4 旋钮网格）：角度输入增益、陀螺输入增益、输出偏置、抽动长度。

## 4. 实验臂

| 臂 | 说明 | 回答什么 |
|---|---|---|
| **E-SNN**（主臂） | 上述完整设置 | 主张本身 |
| C-law | 经典 PLL + 阈值脉冲律，108 点网格调参（v2 的 law_tuned），再加 law_ext | 持平线 |
| C-pid | 重调 PID | 下界 |
| A-nodelay | 延迟基因固定为 0 | 延迟是不是必要的 |
| A-fixed | 固定稠密拓扑（6 隐层单元全连接），只进化权重、τ（无结构变异） | 拓扑搜索是不是必要的 |
| A-ahrs | 输入只有 AHRS 滚转/俯仰（去掉陀螺、加速度计） | 相位信息来自高频 IMU 通道这一机制解释 |
| A-rate | 隐层为非脉冲 tanh 单元（同图、同延迟、同输入），输出仍为阈值事件 | 脉冲本身是否重要（预期：不重要；如实报告） |

每臂 ≥ 3 个种子（主臂 5 个）。所有臂同一训练/验证/选择/测试案例流（v3 seed 3 的流），同一代数与种群。

## 5. 预注册判据

**H1 持平（主结果）**：E-SNN 校准后在旧 16 例与新 16 例上都飞满，且 J ≤ 1.05 × law_tuned；至少 3/5 种子满足。配对 ΔJ 的 95% CI 包含 0 则记为"统计上不可区分"，否则如实报差距。

**H2 机制（涌现的转向肌回路）**，冠军网络需同时满足：
- H2a 相位锁定：上推与下推放电（按真值需求分类，v3 的 `directions` 统计）各 ≥ 20 次，各自 ≥ 70% 落在 135° / 315° ± 67.5° 内，且相位集中度 R ≥ 0.7；
- H2b 相位参考可定位：存在至少一个隐层单元，其放电与真值曲柄相位锁定（R ≥ 0.8，每周期 1–2 次）；把它的输入边切断（或把陀螺/加速度计输入钳位为常数）后 H2a 失效、J 恶化 ≥ 15%；
- H2c 延迟有功能：把隐层→输出的延迟全部置零（权重不变）后 J 恶化 ≥ 10%，或放电相位偏移 ≥ 30°。

**H3 消融**：A-nodelay 与 A-ahrs 的 J 显著高于 E-SNN（配对 CI 不含 0），否则相应机制解释作废；A-fixed 与 A-rate 若与 E-SNN 持平，则如实报告"结构搜索/脉冲本身不是必要条件"。

**判读规则**：H1 且 H2 成立 → 主张成立，进入写作。H1 成立 H2 不成立 → "进化找到了别的解"，报告该解的机制，主张改写。H1 不成立 → 报告为否定结果，附搜索诊断（v4/analysis.md 的盆地方法）。

## 6. 预算与排程

- 一次主臂运行：种群 64 × 40 代 × 4 案例（6 s）≈ 10 240 个 episode ≈ 本机 5.5 h / tanakalab 视核数 / AWS c7a.16xlarge 约 1.6 h。每 4 代做 8 例验证；之后 16 例选择、81 点校准、32 例测试（同 v4/v5）。
- 总量：主臂 5 种子 + 4 个消融臂 × 3 种子 = 17 次 ≈ 95 本机小时。分配：本机与 tanakalab 各 1 次/晚；AWS 承担其余（约 $35）。
- 顺序：(1) v5 结果出来后决定种群/代数是否够（v5 若连比较器都找不到，先修搜索）；(2) 主臂 seed 1 的 `--quick` 冒烟与 1 次正式运行；(3) 主臂其余种子与消融并行。
- 机制分析脚本（与运行无关，可提前写）：放电相位直方图、隐层单元相位锁定表、输入钳位与延迟置零的消融重放、输入权重的 lesion 表。

## 7. 与经典方案的公平性

- 经典律的 PLL 是手工设计并用真值曲柄标定了偏移（84.14°）；E-SNN 没有任何真值信息。这一点对 SNN 不利，写作时要说明。
- 经典律 4 旋钮 108 点网格 ≈ 864 episode；E-SNN 的校准同样是 4 旋钮 81 点；但 E-SNN 的进化预算（约 10 000 episode）远大于经典律的调参预算——这是"学习 vs 设计"的固有不对称，如实写出，并报告经典律在同样 10 000 episode 预算下 CEM 微调的结果作为补充对照。
