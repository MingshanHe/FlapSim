Blind test vs. the re-tuned classical controller

Ratio = learned score ÷ classical median of the same direction class, per case, averaged. Lower is better; 1.00 is a tie. A seed passes when the task average is ≤ 0.95 with no crash.

Robustness rows (plan v12, same frozen v11 controllers): "nominal" is the v11 blind set; kick and ood are new blind sets with a disturbance (kick2 / kick / kick45: a 2 / 3 / 4.5 mN·m torque hit at +0.15–0.45 s; kick_early / kick_late: 3 mN·m at +0–0.15 s / +0.5–1.0 s; ood: +12.5 % body mass). Δ = learned ratio − the classical opponent's own ratio on the identical cases, with a paired bootstrap 95 % CI. A v11 seed passes when the CI lies below 0 and its crashes are ≤ the classical's.
