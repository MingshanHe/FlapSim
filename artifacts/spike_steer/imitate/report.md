# 梯度模仿基线：原始 IMU → 经典律的锁相脉冲（2026-10-13 20:15–21:00）

问题：不给 PLL、不给相位编码，只给 18 维原始 IMU 整流特征，一个带延迟的 LIF 网络里**存在不存在**能复现经典脉冲律的解？用监督替代梯度（BPTT）这个最强的搜索工具来回答。代码 `experiments/algorithms/spike_steer/imitate.py`；torch 模型与仿真里的 `SpikingGraph` 逐拍一致（自测验证），导出的 spec 可直接进闭环与 `pilot_v6 analyze`。

数据：经典律（PID + PLL 律）在 32 个分层应力案例上的逐拍记录（t ≥ 2 s，2000 拍/例），标签 = 该拍是否放电及方向；脉冲率 1.17%。验证集 8 例。

网络：18 输入 → 8 个隐层 LIF（每条输入连接 11 个延迟档 0–20 ms）→ 2 个输出 LIF（每条连接 11 个延迟档）；τ_m、τ_s 共享可学。

## 到目前为止的结论

1. **解存在，而且梯度能找到它**：v1 虽然因假阳性过多（放电 10 倍）坠机，但它放电的**相位是对的**（上推 91% 落在 135°±67.5° 内、R=0.80），飞成的案例俯仰 RMS 与经典律相当。相位参考是从原始陀螺/加速度计里学出来的，没有 PLL。
2. 剩下的是精度问题（假阳性 → 占空比 → 高度逃逸）。pw10 已把飞成率提到 12–13/16，飞成案例的 J 多数**低于**经典律（如 4.4–4.9 对 4.5–5.0），上推相位锁定比经典律更锐（R 0.97）；失败的 7 例全是低余量案例的高度逃逸。pw3（权重 3、50 轮）评估中。
3. 对研究方向的含义：B'（NEAT 涌现）的靶子确实存在于这个输入空间；RL/模仿这类梯度方法在这个问题上是可靠的搜索工具，NEAT 不是。
