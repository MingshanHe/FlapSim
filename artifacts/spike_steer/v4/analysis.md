## 解释

1. **手工构造的比较器解（τ=0.5 ms，J=6.03）确实存在，但 NEAT 从 v1 热启动出发找不到它。** 热启动的解是"慢膜积分、提前充电"的预判策略，它所在的盆地和比较器盆地不同：把 τ 变快（即使保持一拍增益）会破坏它依赖的多拍积分，子代立刻变差，被淘汰；把 τ 变慢反而增强积分，略有收益，于是 τ_m 漂到上界。
2. 所以 v3 的失败是**载体限制和搜索限制叠加**：v3 的固定 τ 表达不了比较器；v4 放开 τ 后，搜索又没有能力跨盆地。
3. 这对"涌现"方向（B）是个警示：如果在给了相位格、给了 PLL、从 v1 热启动的条件下，16 代 × 32 个体都到不了已知的最优结构，那么从原始 IMU、最小拓扑出发"重新发现"转向肌解，所需预算至少高一个量级，而且结果可能仍然是一个次优的预判策略。
4. 盆地宽度见第 5 节。

## 5. 盆地宽度：比较器解不是针尖（`basin/`）

方法：对一个解做 k 轮 NEAT 自身的 `mutate()`（v3 模板的变异率），各 16–32 个突变体，在 8 个分层案例（6 s）上测 J。

**第一轮（作废）**：手工解 G=30 的权重（24/45）和偏置（−60）超出 NEAT 的基因界（权重 ±5、偏置 ±3）10 倍以上，任何一次突变都把越界基因截回界内，门控即坏：1 轮突变 44% 坠机。这是构造越界造成的假象，不是解本身脆弱。

**界内比较器**：在界内能构造出的最陡比较器约 G=2.4（输入权重 1.92/0.96，门控权重 2.8，偏置恰为 −3.0；门内在 u≈0.51 过阈值，门外要到 u≥1.67 才误触发）。τ=0.5 ms，抽动 2 拍。

| 解 | 未突变 J | 1 轮突变：中位 J / 落在 +0.5 内 / 坠机 | 2 轮 | 4 轮 |
|---|---|---|---|---|
| **界内比较器** | **5.76** | 5.78 / 88% / 0% | 5.80 / 75% / 3% | 6.03 / 56% / 12% |
| v4 冠军 | 6.81 | 7.23 / 50% / 0% | 7.38 / 47% / 22% | 8.94 / 25% / 31% |
| v3 冠军 | 6.50 | 7.51 / 38% / 0% | 8.12 / 31% / 16% | 9.29 / 25% / 31% |

结论：
1. **界内比较器是这 8 个案例上最好的解（5.76），而且比两个进化冠军更鲁棒**：盆地更宽、更平。它不是针尖。
2. 它完全在 NEAT 的基因型空间里：两个输出神经元、无隐层、5 条直连边各，再加 τ。
3. 所以 v1–v4 四次都没找到它，是**搜索设计问题**：热启动和「6 个隐层 LIF 读全部输入」的稠密初始化把种群放进了另一个盆地（慢膜积分预判），从那里到比较器需要同时做到「输出 τ 变快」和「隐层静默」，单步突变做不到，选择就一直守着慢膜解。
4. NEAT 的经典起点（输入直连输出、无隐层、小权重）就在比较器盆地的邻域里。一个用经典起点、τ 可进化（增益保持）的 v5 很可能直接找到它，但那在科学上是平凡的：给了相位格和需求输入，线性阈值单元就是显然解。
5. 把 NEAT 配置里的权重界放宽到 ±30 以上，比较器的斜率可以更陡（手工 G=30 版 J 5.92，和 G=2.4 的 5.76 差不多——所以斜率 2.4 已经够用，界不是瓶颈）。

## 7. v1–v4 的统一结论

1. 任务的最优结构是"线性需求过阈值 × 相位门控"，经典、4 个旋钮、已到上限（law_ext 无增益）。
2. 脉冲载体在 NEAT 基因界内能表达它，且该解鲁棒（第 5 节）、达标（第 6 节）。
3. NEAT 四次没找到它，根因是初始化：稠密 6 隐层起点 + v1 热启动把种群放进"慢膜积分预判"盆地；v3 的固定 τ 是第二道障碍。
4. 用 NEAT 经典起点（输入直连输出、τ 可进化、增益保持）的 v5 很可能直接找到比较器并过线，但那是平凡的；有实质内容的问题只剩一个：**不给相位格和 PLL、只给原始 IMU，进化能否自己搭出相位参考**（1 个阈值检测神经元 + 1 条延迟边 + 2 个比较器）。
